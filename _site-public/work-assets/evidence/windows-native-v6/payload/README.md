# Windows Endpoint Readiness evidence

This package contains five Windows captures for each controlled scenario: two healthy baselines, the failure, the corrected state, and a fresh disposable-session rollback. Each stage includes machine-readable collector facts and a sanitized command transcript. Structured collection-attempt and negative-control results remain attached to every stage.

The package does not claim that synthetic fixtures or screenshots prove the native Windows outcomes. The source hashes bind each public artifact to the retained private original.
